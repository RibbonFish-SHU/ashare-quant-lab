## 实际读取结果

完整归档清点得到 61,062 个成员、525,329,303 字节未压缩文件内容；
`all.txt` 与 feature 目录包含 5,550 个证券代码。两个日历文件均为
2005-01-04 至 2023-12-29，共 4,616 个交易日，其中 2023 年 242 日。
这些是包结构和日历范围，不代表每个代码在全部年份都完整。

每个代码有十个 float32 字段：`open/high/low/close/volume/amount/factor/adjclose/change/vwap`。
已提取六只样本：600000、688065、000001、000938、300308、301269。
Qlib 0.9.7 原生 provider 读取其 2023 年 1,452 行、五字段，共 7,260 个值，
与直接读取二进制一致；没有训练模型或运行回测。

用 `normalized OHLC / factor` 恢复价格，与保留的 BaoStock / 东方财富候选比较：

| 项目 | 结果 |
| --- | --- |
| 六只证券的参考重叠 | 每只 242 日，共 1,452 日线位置 |
| 可比较的开高低收 | 5,792 个，分币精度全部一致 |
| 最大未舍入价格差 | 约 0.0000122 元，保留 float32 误差 |
| 不可比较价格 | 688065 的四日，共 16 个值为缺失 |
| 四日的已有参考 | 06-16、06-19、06-20、06-21，BaoStock 标记停牌、零成交量 |

不能将其他缺值也一律解释成停牌。`volume * factor * 100` 和 `amount * 1000`
只作本次单位诊断：样本最大误差分别约 53.77 股、352 元，不能声称是无损原始量额。
社区项目混合多个上游，和 BaoStock 的一致性也不自动构成完全独立来源证明。

### 扩展到原计划 336 只

六只样本核验后，继续离线检查原计划全部 336 个代码：均存在于包内证券清单和十字段目录。
全部 55,500 个 feature 文件的起始偏移与长度都落在 2023 年末以前的日历内。
随后只解码这 336 只的 OHLC / factor，与既有三个候选目录的 **81,296 行**比较：

- **325,116 个可比较 OHLC 在分币精度上全部一致**；最大未舍入误差约 0.0001573 元。
- 包内缺值对应 17 个证券交易日 / 68 个价格值，分别是 600372 七日、601916 六日、688065 四日；
  已有 BaoStock 原件均明确标记当日未交易。保留缺值与状态证据，不进行前向填充。
- 601059 的包内起始日为 2023-02-01，不能因为全年日历完整而补造上市前行情。
- 量额仍只有前述六只的单位 / 精度诊断；该扩展没有认证所有年份、状态或历史可用时间。

这一步解决了“包中是否含原计划证券、2023 价格是否与已有候选吻合”的具体问题。
首次输出因 NumPy 标量不能直接写入 JSON 失败；转换为 Python 浮点后仅重跑离线核对，
失败脚本和记录保留，没有重新下载。见[336 只扩展核验](evidence/phase1_community_336_audit.json)。

## 历史成分能提供什么

包内 `csi300.txt` 有 14,398 个历史成员区间，来自 Tushare `ts_index_weight` 快照。
2023-01-03 的 300 只与此前“修正 BaoStock 陈旧快照并应用官方公告”的条件集合完全一致。
这增加了覆盖全部 300 只的社区来源互证；基准不再只有单个供应商的错误快照和 15 对调整。

但不能原样使用全部区间。对 2023 年 242 个交易日核对：215 日与条件重建一致，27 日有差异。

| 官方事件 | 官方首个生效交易日 | 包内情况 | 可证实的差异 |
| --- | --- | --- | --- |
| 14796，调入 / 调出各 9 只 | 2023-06-12 | 到 06-30 才变更 | 06-12 至 06-29 的 12 个交易日仍保留旧集合 |
| 15044，调入 / 调出各 14 只 | 2023-12-11 | 年末仍未反映 | 12-11 至 12-29 的 15 个交易日仍保留旧集合 |

原导出程序按权重快照的成员签名取最早日期、延伸区间；它没有公告时间和精确生效日字段。
因此后续使用社区基准时，应显式应用已核验的官方事件，保留修改依据和原区间，
继续核实临时事件覆盖。不能因为两个集合吻合就认证完整历史 PIT 股票池。
原 336 代码采集计划、旧快照和所有原始文件继续保留。

## 官方公司行为公告补充探针

另用巨潮资讯公开网页接口查询 000938 / 300308 的 2023 年“权益分派实施”公告，
共一次代码路由字典、两次有界搜索和一次 PDF 下载，没有账户或 token。
000938 在该关键词 / 分类组合下为零条，不能据此断言没有公司行为；
300308 返回一份[2022 年度权益分派实施公告](https://static.cninfo.com.cn/finalpage/2023-05-30/1216935954.PDF)。
四页 PDF 均已提取文本并渲染核对，登记日为 2023-06-05，除息及代派到账日为 06-06。
报告年度 2022、公告日期 2023-05-30、权益日期是三个不同概念。

原件明确：符合条件的股东每股获得税前现金 **0.2 元**，但因回购专户股份不参与分配，
按总股本折算的除息扣减为 **0.195898 元 / 股**。这两个字段不能混用；
税后金额也随持有人类型和持股期限变化。社区包相邻两日的 factor 比值未精确等于
任一现金口径下的理论比值，归一化 / 舍入与上游复权约定尚未解释，不能代替事件原件。

网页时间戳对应上海零点日期标签，不证明该公告当日零点即已公开；
目前仅确认日期粒度，历史精确 `available_time` 保持未知。
这是免费官方公司行为来源可访问的实证，还没有完成年度事件覆盖或生产适配。
证据：[官方公告有限探针](evidence/phase1_cninfo_actions_probe.json)。

## 接入决定与剩余范围

1. 将该历史包列为已实测的免费离线行情 / 复权参考候选；已有原始日线继续作为核对依据。
   不再把“没有付费数据权限”当作工程推进前提。
2. 下一步限定为旧包的离线适配与 2023 年范围核验，保存包摘要、字段误差和每行文件定位。
   不用调整后价格代替实际成交价，不把量额强行变成精确整数。
3. 十个导出字段没有显式 ST / 停复牌、每日精确涨跌停价、历史公告 / 修订时间或逐行上游来源。
   这些仍需官方公开资料和独立状态证据。上游的涨跌停表另有推算规则，尚未下载或验收。
4. 仓库代码当前采用 Apache-2.0，但混合上游数据的统一开放许可未核实；本轮认定的是
   可公开下载的数据候选，不将代码许可证扩展为全部数据的再分发授权。

当前 `research_eligible=false`；可继续数据工程和质量核验，正式收益比较需满足项目研究契约。
本轮所有下载和检查已退出，没有服务器同步、GPU 占用或外部仓库修改。

版本化摘要：[社区包主审证据](evidence/phase1_community_dataset_audit.json)。
完整抽样文件中一处说明文字误写“五只有参考”，实际六只均有 242 行参考；
版本化摘要按计算结果记录六只，并保留该文字勘误，不重复实验。
