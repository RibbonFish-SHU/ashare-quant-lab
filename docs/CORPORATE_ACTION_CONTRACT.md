# 合成公司行为生命周期账本 v1

`ashare_lab.corporate_actions` 在已有合成执行器之上处理现金分红与整数送股 / 资本公积转增。
登记日持仓决定权利；除权除息、现金支付、股份到账和可卖日分别记账。本版只用于工程验收，
所有输入必须声明 `data_kind="synthetic"`，导出和 smoke 始终为 `research_eligible=false`。
不加载真实公告候选，不认证历史数据，不接入券商，不产生策略绩效。

## 输入与权利

| 对象 | 必填语义 |
| --- | --- |
| `CorporateAction` | 事件 ID、正整数版本、证券、登记日、除权日、带时区的发布时间和可用时间、实施阶段及显式合成认证声明 |
| `CashDividend` | 每股有权股份的税前现金、最早支付日期、显式税收假设及代扣比例 |
| `ShareDistribution` | `stock_bonus` 或 `capital_reserve_conversion`、每股旧股获新增股比例、到账日期、上市日期、明确可卖日期、整数分配和成本政策 |
| `ActionState` | 账户标识、复制的现金持仓账户、交易日历、单调时钟、登记快照、权益、分录及完整性摘要 |

只接受实施版本且 `certified is True`；这个布尔值只是合成场景声明，不能证明真实来源。
现金和股份条款至少提供一项。金额和比例使用 `Decimal`、十进制文本或整数，不接受浮点数、
布尔值、负值、NaN 或无穷值。证券为六位 ASCII 数字和 `.SH` / `.SZ` 后缀。
未知可用时间、无时区时间、预案、未知税率或分配规则都会失败。

`capture_record_close` 只能在登记日上海时间 15:00 或之后冻结持仓。该日期必须在显式交易日历中；
记录账户、证券、登记日、捕获时刻、全部持仓批次和账户摘要。尚处于 T+1 / 上市锁定期的
**已到账持股**也计入登记股数。登记后卖出保留本次分红权；登记后买入不追溯增加本次权益。
公告可用时间不得晚于冻结时点，也不得晚于处理时点。

同一快照 ID 只能重放完全一致的账户、证券、日期和捕获时点。不能换 ID 重新冻结同证券同登记日。
同一证券已有数量非零的送转股权益尚未到账时，拒绝新的登记快照，避免后续公司行为的权利基数
仅使用部分持仓；这一有限版本不实现未到账股份再参与分配的复杂规则。零权益或只有现金应收不触发此限制。

现金权利使用 `gross_cash_per_eligible_share × 登记持股数`。可选的
`ex_price_deduction_per_total_share` 仅保留为场景输入，**从不替代每股有权股份的现金**，
也不用于自动调整行情价格。股份权利使用 `new_shares_per_old_share × 登记持股数`，
结果必须为整数；任何零碎股都直接拒绝，不向下取整、不默认为零。

## 阶段与时间

| 阶段 | 前置与时间 | 对可交易账户的影响 |
| --- | --- | --- |
| `register` | 已冻结匹配快照，必须在登记日处理 | 固定权益，无现金或持仓变化 |
| `ex_accrual` | 已登记，必须在声明的除权除息日处理 | 产生税前应收、合成代扣待付和未到账股数；不增加可用现金 / 实际股份 |
| `cash_payment` | 已除息，实际处理日不早于声明支付日 | 税后金额一次进入可用现金，冲销税前应收及代扣待付，记录已代扣金额 |
| `share_credit` | 已除权，实际处理日不早于声明到账日 | 一次新增整数持仓批次，独立设置可卖日 |

登记日必须早于除权日，两者都要在显式交易日历中。支付、到账、上市、明确可卖日期都不得
早于除权日。现金支付可发生在非交易日；新增股份最终可卖日期必须存在于本版交易日历中，
不自动把缺失日推进到下一个交易日。

未处理的新阶段必须满足 `at >= state.clock`。除权阶段不能在后来补写成历史已处理。
支付和股份到账允许晚于条款日期，记录 `applied_at` 为实际处理时刻，不回填声明日期。
新增股份的可卖日起点为 `max(实际到账的上海日期, 上市日期, 明确可卖日期)`。
当日盘后到账也不会支持回到当日开盘交易，因为状态时钟已前进。

阶段以事件 ID 和阶段名去重，摘要绑定完整事件、版本、日期、金额与快照 ID。
已完成阶段的相同内容重放不新增分录、不改变当前时钟；重放时刻不能早于该阶段原处理时刻。
相同 ID 更换金额、日期、版本或快照会失败。本版不做冲正 / 更正重算；同证券同登记日同除权日
也不允许换事件 ID 再分配，现金与送转条款应合并在同一事件中。

## 税收、成本与估值限制

- `synthetic_no_tax` 要求代扣比例为零；`synthetic_flat_withholding` 要求显式比例在 `[0, 1]`。
  二者都是合成假设，**未实现 A 股持有期税收、卖出后补扣税和投资者身份差异**。
- 税前现金按聚合登记持股计算，使用 `ROUND_HALF_UP` 舍入到人民币分；代扣金额按已舍入税前现金
  乘固定比例后再舍入到分。税后到账加本次代扣必须等于税前权益。
- 唯一成本政策为 `original_lots_unchanged_new_shares_zero_cost`：原持仓批次股数与单位成本不变，
  送转新增股单位成本为零，聚合取得成本保持不变。**这不是实际税基或完整收益核算**。
- `cash_claims` 分别返回可用现金、税前应收、代扣待付、税后应收和未到账股份。
  没有公司行为调整后的完整估值器，`complete_portfolio_valuation_available=false`。
  不能把原执行器仅含已到账资产的市值当作含全部权益的 NAV；本版不计算公司行为总回报。
- 不支持配股认购、拆并股、现金替代零碎股、退市清偿、撤销及复杂重组。

## 与执行器组合

`execute_session` 仅接受上海时间 09:30 的单场显式订单列表，复用原 `execute_orders`，
保留费用、容量、T+1、限价、拒单和不能透支的规则。只把 `Account` 中实际现金和已到账批次传入执行器，
应收现金与未到账股份不可花费 / 卖出。原批次的 T+1 约束不因送转而解除。

调用方必须提供 `ActionGuard`，本模块不自动生成、修改或放行 guard。合成 smoke 明确构造场景及
每次会话声明；这不能映射为真实公告覆盖证明。已登记且除权日已到、却尚未处理 `ex_accrual` 的事件
会额外阻止后续交易。未知事件仍依赖调用方的完整性门禁，不能用本模块已处理的部分事件证明没有其他行为。

同一开盘不能换 session ID 再执行。同一 session ID 只有完全相同的输入才能无变化重放。
成交结果及原执行分录以 JSON 保存在对应执行 `JournalEntry.notes[0]`，其现金前后值进入统一分录链。

## 保存、恢复与原子性

`export_state(state)` 返回可 JSON 序列化的完整审计状态，包含阶段身份、账户、权益和分录。
保存之前独立保留 `state.integrity`，恢复使用：

```python
checkpoint = export_state(state)
trusted_digest = state.integrity
# checkpoint 可以写入 JSON 并在另一进程读取；trusted_digest 必须由调用方独立保存。
restored = restore_state(checkpoint, expected_integrity=trusted_digest)
```

恢复重建类型，并核对外部摘要、schema / synthetic 声明、账户和快照身份、快照时间顺序、
权益计算、阶段前置与唯一性、分录时钟、逐条现金和账户摘要链、最后账户及派生应收。
不能从待验证 payload 自取其摘要作为独立校验值。SHA-256 只验证内容一致性，不证明数据来源或公告认证。

公开操作复制账户，外部更改账户、快照或状态会破坏摘要并被拒绝。`apply_actions` 的批次在
全部步骤成功后才返回新状态；后续步骤失败时输入保持完整。
这是单所有者状态链，不提供跨进程锁、数据库事务或 compare-and-swap。调用方负责原子保存最新状态、
独立保存摘要并避免并发分叉；不能把同一旧检查点的两条独立运行当作自动协调过的账户。

## 验证与复现

在项目已有环境中运行，无需准备 GPU、下载数据或安装另一环境：

```powershell
.venv\Scripts\python.exe -m pytest -q tests/test_corporate_actions.py tests/test_corporate_action_smoke.py tests/test_execution.py tests/test_execution_smoke.py
.venv\Scripts\python.exe scripts/run_corporate_action_smoke.py
```

在独立 worktree 复用主仓库解释器时，应将 `PYTHONPATH` 显式设为该 worktree 的 `src`。
正式 smoke 要求干净提交，校验实际加载模块与脚本所属根、源码与提交内容，并在运行前后再次核对来源。
跨 worktree 导入、脏源码或运行中来源变化均失败。

每次运行在 `artifacts/experiments/synthetic/` 下建立带 UTC 时间戳和随机后缀的独立目录。
保留 `inputs.json`、逐阶段 `trace.json`、`checkpoint.json` 与摘要、`journal.json`、
`final_state.json`、`result.json` 和含源码 / 产物 SHA-256 的 `manifest.json`。
失败保留已产生文件、错误与 traceback，退出码非零；判断通过必须查看 manifest 状态，
不能仅因存在 `result.json` 就声称成功。

固定合成样例由 200 股登记持仓产生税前 250 元、假设代扣 25 元、税后 225 元以及 100 股送股。
应收阶段买单因无现金拒绝，送股锁定时只卖出旧股；原持仓卖出后仍收到分红，延迟到账按实际时刻记录。
保存恢复和重复处理均不二次入账，随后只在明确可卖日卖出送股。最终现金 3125 元仅用于核对账本，
不输出收益率、NAV 或真实策略绩效。
