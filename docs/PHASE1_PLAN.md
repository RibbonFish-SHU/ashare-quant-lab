# Phase 1 首批任务：免费来源采集、适配与质量审核

维护者：主代理；日期：2026-10-03。依据用户原方案、免费来源核验结果及持续推进要求制定。
执行代理完成当前 Linux / CUDA 批次并交接后继续此任务；主代理并行审阅和集成，不等待用户再次催促。

## 当前依据与首批范围

- 用户没有现成数据，已明确先核验免费来源。BaoStock 0.9.4 匿名服务可用；历史成分按周更新。
- 2010–2023 各年份均取得可读样本，一个中证官方调样事件的 18 个代码与供应商完全吻合。
  原始读取成功不代表成员时点已通过；2022 / 2023 年初快照有明显陈旧的更新日期。
- 先在 **2023-01-01 至 2023-12-31** 做有边界的真实数据工程闭环，再依据质量报告扩展至
  2010–2023。这段是开发期，选择依据是数据接口 / 公告已核实，未依据策略表现选择。
- 2024–2025 仍为候选最终封存区间；此批次不采集该区间行情、不训练模型、不运行回测。
- 先完成可重放采集、字段适配与明确缺口，不能把接口成功或快照存在等同于严格 PIT 通过。

## 实现与产物

1. **受控采集入口**：锁定 BaoStock 0.9.4 为明确的来源依赖；沿用已经通过的研究依赖版本。
   提供带日期范围、来源、配置与运行清单的 CLI。默认单连接串行查询，设置超时、有限重试、
   持久日志与断点复用；错误码、空返回和部分结果不可混为完整成功。
   先读取官方访问规则，按其限制设置请求节奏；遇到限制后记录并停止相应请求，不绕过限制。
2. **原始层**：每次返回保留完整字段、参数、SDK 版本、实际获取时点、来源 URL / API 与摘要。
   当前已有 raw 快照可复用，不重复抓取已通过且参数一致的样本。
   采集股票池、日历、未复权行情、证券基本信息、分红实施信息和复权因子；数据及下载包不进入 Git。
3. **历史成员**：从 2023 年起点快照和周度快照发现变更候选，使用中证官方公告确认生效事件。
   优先核对年初基准：2023-01-03 查询返回 updateDate=2022-08-01，必须核对 2022 年末官方调样。
   仅有更新日期陈旧或 300 个代码均不足以判定正确 / 错误，须实际比较成员集合。
   保存公告日期 / 精度、原件摘要和生效语义；不能将 updateDate 写成公告时间。
   覆盖定期和临时变更，报告无法对应公告的差异。成员缺口不得通过当前成分回填。
4. **供应商适配**：先实现纯函数转换与质量分类，再接入持久化。严格区分合法非交易、原始缺失、
   供应商错误和类型错误。无法确认的记录保留原始值并产生可定位的问题，不能静默填零 / 丢行。
5. **质量报告**：覆盖率、重复键、交易日缺行、上市 / 退市边界、停牌、ST / *ST、成员变更、
   公司行为、时点精度和历史修订风险均有计数及样例定位。每项区分“通过、失败、未核实”，
   非零退出或明确非通过状态阻止不合格数据进入正式研究。
6. **实际闭环**：从可追溯采集结果生成原始快照、标准化候选和机器可读质量报告；
   用真实代表样本跑完一次。测试以真实发现的错误及有效边界为依据，不依靠网络来跑单元测试。

## 已发现并必须覆盖的语义

| 主题 | 明确要求 / 可复核案例 |
| --- | --- |
| 股票编码 | `sh.600000` / `sz.000001` 显式转为 `600000.SH` / `000001.SZ`，校验市场与类型 |
| 行情单位 | volume 为股、amount 为人民币元；供应商 turn 为百分数，规范 turnover 为小数比例，需除以 100 |
| 停牌 | 供应商可沿用前收盘价且量为零；价格存在不能认定成交。不能将缺失开盘价用于标签或交易 |
| 退市 | 600747 在 2019-12-12 出现量 / 金额空字符串，原始 outDate 为该日；明确日期口径后分类，不能填成正常行情 |
| 税与分红 | 600000 在 2023 年的税后现金为文本 `0.288或0.32`，不能转为任意一个固定浮点税率；税前金额与原始税后表达分开保存 |
| 公告阶段 | 分红预案与实施公告分开；最终实施字段不能按更早的预案公告时间回填 |
| 公司行为日期 | 登记、除权、派息、红股上市可不同：600000 2010 年分别为 06-09、06-10、06-18、06-11，不能统一为一个现金 / 持仓生效日 |
| 因子定义 | 2023-07-21 600000 后复权因子由 11.434431 变为 11.949786；相邻比值约 1.045070454，与 7.42 / 7.10 在供应商精度内一致。不能把累计因子直接当成本次拆股倍数；字段名和简表不足以证明完整算法 |
| 调样日期 | 官方公告 14796：2023-05-26 发布、06-09 收市后生效、次一交易日 06-12；周度快照不能提前应用于此前交易日 |
| 日级公告 | 原来源只有日期时，保留时间精度与依据；若使用次日零点的保守上界，必须在契约 / 清单显式标记其为上界，不能伪称精确发布时间 |
| 历史修订 | 官网披露过 2020 年修改 2015 年数据、补充 isST 等事件。当前下载是当前版本；不能仅凭现在的 17:30 / 18:00 更新说明将全部记录宣称为历史 vintage |

现有 actions 是 Phase 0 的简化交换契约。正式适配若需扩展事件日期或来源精度，应做显式 schema
版本处理并保留旧快照与证据；不要为了通过旧 schema 丢弃上述有业务含义的字段。

## 研究资格与时序

- 原始捕获时间是 observed / ingested 时间。来源事件日期、公告日期、可用时间依据和修订版本分别记录。
- 纯 raw 快照默认 `research_eligible=false`。具备可追溯公告 / 可用时间依据的记录与仅有日更时间表
  假设的记录分别标记，当前快照不能靠改字段名自动升级为历史 PIT。
- 首批工程输出可以是不完整的标准化候选，但质量报告必须指出阻碍正式研究的具体字段、日期和记录。
  不把不完整结果包装成基线，也不因一个资格缺口停止全部采集 / 适配工作。
- 下一阶段训练前由主代理根据覆盖冻结滚动窗口、封存窗口、特征拟合范围与标签成熟规则；
  继续采用收盘后信号、下一交易日开盘至第六个交易日开盘的五个交易间隔。
- 特征价格与组合实际现金流分开；复权收益标签不能替代后续包含分红、交易成本与执行约束的回测。
