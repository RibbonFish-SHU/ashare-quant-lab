## 实现

1. 显式的离线状态证据入口，校验输入摘要、来源身份、股票代码、原公告 / 原 XLSX 单元格与
   提取结果的一致性。证据选择及手工审核字段放在版本化配置中，不能只相信汇总里的 pass。
   原件不修改，输出到新的候选命名空间，仍 `research_eligible=false`。
2. 名称事件保存生效日期、变更前后名称和表格行 / 单元格定位；不读取当前简称 C 列来填历史。
   对有事件者保留未验证的连续性假设；没有事件不能补成“非 ST”。ST 字符串诊断与已认证的
   风险警示区间分开，未知字段为 null，不凭当下名称或全年有成交证明全年非 ST。
3. 停牌 / 复牌分别是独立事件，支持 `afternoon_open`、`morning_open` 的时段锚点。
   公告没有明确时分时保留锚点，不能默填 00:00 或凭代码写入未经核验的交易时钟。
   日级供应商标记与交易量保留原语义；688065 的 06-15 非零成交可以与下午停牌并存，
   四个完整停牌日是另一类。价格缺失不能自动转换为停牌事件。
4. 单独保存正文事件日期、原件落款、来源时间字段、精度与实际观察时间。
   2023-019 的原落款年份冲突应可见。未知历史可用时间继续未知，不能由本次下载时刻倒推。
5. 提供按指定事件时间 / 证据可用时点检查的纯函数。缺少 availability 的真实证据可出现在
   事后参考视图，但严格 as-of 视图不能默认认为其当时已知。只有明确时点证据或显式记录的
   保守时间政策才能进入相应视图，默认不采纳日期零点假设。后来的复牌事件不能提前闭合停牌。
6. 输出质量报告，统计已核对事件、无法定时的证据、未覆盖股票 / 日期、冲突和失效输入。
   东方财富本轮返回后续开始日期的响应仅作接口失败证据，不进入 2023 年状态表。
