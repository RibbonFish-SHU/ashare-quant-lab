# 含公司行为权益的合成收盘估值

主代理，2026-10-04。公告时间诊断已集成后，直接推进本独立工程批次。

## 目标与范围

已有执行器只估值可用现金和已到账股份；公司行为账本另存现金应收、代扣待付及未到账送转股。
新增独立估值层，避免除息日遗漏权益、派息或股份到账日重复增加资产。
使用已有合成 `ActionState`，不修改历史候选、真实数据门禁、执行规则或公司行为记账语义。

本批只提供可核对的合成收盘资产分解，不输出正式回测、年化收益或策略结论。
NAV 定义为可用现金 + 已到账股份市值 + 税前应收 - 合成代扣待付 + 未到账股份的假设市值。
未到可卖日的已到账股份仍须估值；应收及未到账股份继续不能用于交易。

## 必须明确的输入与行为

- 查询包含显式交易日、带时区的收盘后知识时点和已完整处理到该时点的状态。
  拒绝状态时钟在查询未来、非交易日、上海日期不符及盘前查询。
- 每个有已到账股份或非零待到账股份的证券都要求同日、当时已可见、正值的价格。
  价格必须显式声明未复权；复权价与另计权益会重复补偿，因此拒绝不明口径或复权价。
  不自动用昨日价格补停牌日，不把缺价当零。
- 对未到账普通股，调用方必须明确选择“与同证券未复权收盘价相同”的合成估值假设。
  不声称这证明真实受限股份的公允价值；价格缺失仍失败。
- 调用方须显式声明本合成场景公司行为范围完整，默认未知失败。
  对已登记且除权日已到却未计提的已知事件，额外拒绝估值，不能靠声明绕过账本阶段检查。
- 登记至除息前不提前增加应收或未到账股价值；除息后计入；支付 / 到账后从应收转资产，
  不重复计值。只剩现金应收的证券不要求股价，零股数的条目也不制造缺价门槛。
- 使用 Decimal，输出现金、税前 / 税后应收、代扣待付、已到账市值、待到账市值、合计和逐证券分解，
  绑定账户、状态摘要、日期、知识时点、价格口径和假设。
  不修改状态、行情或调用方字典；所有输出始终标为 synthetic、`research_eligible=false`。
- 已有 `complete_portfolio_valuation_available=false` 及旧导出格式保持含义；新接口用明确的
  “所支持的合成范围已估值”字段，不宣传为所有真实公司行为的完整估值器。
