零股清仓、按证券共享的会话容量、含费现金约束、部分成交及拒单、收盘估值。
完整接口与公司行为日期契约见 [EXECUTION_CONTRACT.md](EXECUTION_CONTRACT.md)。

主审修复了直接订单绕过次交易日校验、重复使用开盘容量、行情字典串证券、清仓后空持仓仍索要价格、
科创板小持仓因总目标数量取整被错误清仓、分价舍入后触及限价仍成交、小额卖出费用导致负现金等问题。
来源标记在账户复制中保留，信号与估值使用上海日期并要求收盘后显式知识时点。
停牌、未知交易状态、未知限价 / 容量和未处理公司行为均有拒绝路径。

模块只接受合成输入，没有真实候选适配器；公司行为门禁默认未知，未处理的持有证券也会阻止整个会话。
同一开盘必须由调用方合并为一次会话。本版没有跨调用的持久订单去重、真实撮合队列和现金 / 股份行为处理器。
