## 已实测与选择

BaoStock 受限后，主代理向东方财富、腾讯这两个独立公开服务共发出 **7 次**有明确 2023 日期范围的
未复权日线请求；没有再请求 BaoStock，也没有切换其账户、端点或出口。
取得 54 行历史日线原始记录，其中 33 行处于请求区间；28 行能与已保留 BaoStock 样本对照，
**112 个 OHLC 数值全部一致**。七份返回均完成原始行的 Parquet / DuckDB 读取核对。

| 来源 | 本次请求 / 原始行 / 区间内行 | 发现 |

| 东方财富 | 3 / 14 / 14 | 三只股票的价格一致；成交量为整手显示，成交额与 BaoStock 样本最大差 0.40 元 |
| 腾讯 | 4 / 40 / 19 | 返回 end 之前的最近 10 行，样本中未严格遵守 start；额外 21 行保留于 raw，但不纳入请求区间比较 |

## 适配必须保留的区别

- 东方财富样本成交量为手，乘 100 只得到按其显示精度换算的股数，不能标成精确成交股数。
  原始单位、原始数值、换算比例和已知精度分别记录。不要擅自把所有误差假定为某一种四舍五入规则。
- 腾讯的 688065 原值为股，600000 / 000001 原值为手。000001 在 2023-07-18 返回 471966，
  BaoStock 为 47,196,618 股，证明该样本需要乘 100。所读取的 AKShare 腾讯实现却将 sz000
  与指数前缀一并排除换算，不能直接依赖该包装函数的统一单位声明。
- 参考包装器可能先查询最新数据或扩大到后续年份。下一批只调用已经核对的日期限定日线接口，
  不执行包装器的默认范围、当前股票池或最新行情流程。
- 原始 HTTP 响应完整保留，严格解析 JSON / JSONP；禁止执行响应中的代码。保存参数、观察时点、
  HTTP 状态、摘要和错误。供应商返回的当前名称 / 当前报价不能回填为历史特征。
- 缺行不等于停牌；688065 在 06-16、06-19、06-20 的空缺需要已有停复牌证据解释，
  06-15 的价格 / 成交量吻合仍不证明日内停牌起止。未知交易状态及 ST 标记保持未知。
- 不把涨跌额 / 涨跌幅字段自动换算为交易用前收；600000 除息日的供应商百分比口径与复权参考价
  不同，正式标签与公司行为处理仍须独立定义。

## 下一工程批次

执行代理先完成当前主审完整性修复，再在独立 worktree 实现补充行情入口；主代理拥有本方案及最终集成。
以现有 2023 证券计划为输入，精确列出缺失日线代码，并保存来源、计划身份和成功 / 缺失请求计数。

1. 先复用主代理七份原件完成离线适配 / 单位 / 日期边界检查；接口相同参数不重复抓取。
2. 增加来源独立的受控采集，显式代码、起止日期、未复权模式、串行请求、至少 1 秒间隔、
   有限超时与重试。受限 / challenge / 验证码立即记录并停止该来源；不切端点规避。
   当前没有核实官方每日数额承诺，不引用第三方“无限制”作为批量依据。
3. 首次新联网批次最多 **10 个缺失股票、仅 2023 全年日线**。以小批次实际返回确认单位、
   日期覆盖和容量，再由主代理按质量报告安排剩余范围。不得请求 2024–2025 行情。
4. 输出与原有 raw 分开的不可覆盖快照、明确版本的候选行情及质量报告。规范字段保留精度信息，
   不与 BaoStock 记录悄悄拼成一个来源；供应商冲突必须有逐字段定位。
5. 日期覆盖使用已有日历及上市信息；未知字段保持空值 / unverified，不能凭返回成功获得研究资格。
   检查成功空返回、截断、乱序、重复日期、越界日期、单位差异与来源限制；测试不依赖在线服务。

代码 / 测试 / 采集进程与运行报告由执行代理负责。旧 Phase 1 worktree、限制账本和全部原始产物继续保留。
