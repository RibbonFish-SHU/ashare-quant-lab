## 对后续适配的实际要求

- **成员时点**：官网明确每周一下午更新成员；6 月 9 日返回 updateDate=6 月 5 日。
  精确生效日需要公告 / 生效事件层，不能将周度快照假装成每日无遗漏的变更记录。
- **数据可用时间**：官方当前说明日线 17:30、复权 18:00 入库；这些时间不能证明历史 vintage。
  本次捕获时间只写作观察时间，不回填为历史 publish_time / available_time。
- **停牌与退市**：退市样本末段有价格沿用、零量与空量；以状态及真实成交条件判断，不能用价格存在推断可成交。
  outDate 与项目“退市生效首个自然日”的转换仍须独立规则证据。
- **复权与限制价格**：当前因子快照不能直接视为历史时点已知；涨跌停价、完整 ST / *ST 变化及复杂公司行为仍需补齐。
- **覆盖与封存**：先继续核验 2010–2023 开发期的代表年份与变更，不读取拟封存的 2024–2025 行情 / 模型结果。

下一步在原始层之上实现有来源依据的适配与质量报告，先处理上述明确缺口，再开放研究快照。
源服务可用和一个调样吻合均不能替代完整历史成分 / 状态验收。
