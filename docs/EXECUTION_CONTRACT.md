# 合成执行与现金持仓账本 v1

此模块用于先验证执行规则和账本。入口 `ashare_lab.execution`，可运行示例为
`scripts/run_execution_smoke.py`。输入对象只接受 `data_kind="synthetic"`；没有真实候选加载器、
券商连接、模型或策略绩效输出。人工标记不能证明数据来源，真实候选仍受原研究资格门禁约束。

## 订单、时点和账户

- 交易日历必须非空、唯一、升序。每笔订单的提交日必须在日历中，执行日必须是下一交易日。
  同一调用只处理一个开盘时段，订单 ID 非空且唯一。五日辅助函数按日历索引产生信号 / 执行日对，
  不用自然日加五，也不证明真实交易日历完整。
- 等权信号使用上海交易日期，信号不早于当日 15:00；收盘价可用时点不得早于对应日收盘，
  也不得晚于信号时点。证券标识必须与字典键相同，防止串用其他证券的行情。
- 账户保存 Decimal 现金和持仓批次。批次包含股数、可卖起日与成交单价；成交单价不含费用，
  费用单独记账，不据此计算税务成本或已实现损益。执行复制输入账户，拒单保留原因。
- 同一时段先卖后买，各方向保持原顺序。新买股份从日历的下一交易日起可卖；没有后续结算日则拒买。
  卖出仅消耗已可卖批次，按输入批次顺序扣除。无融券、无透支；全部卖空后不再把空列表视为持仓。
- 容量为调用方显式给出的开盘股数乘参与率后向下取整，按证券在同一会话内共享并逐笔扣减。
  不以全天成交量代替开盘容量。调用方负责将同一开盘的全部订单放入一个会话；
  本底座没有跨调用的持久订单去重或交易所撮合队列。

## 成交条件与交易单位

| 输入 | 本版处理 |
| --- | --- |
| 状态未知、缺证券观察或日期不符 | 拒单，不从已有价格推断可交易 |
| 停牌 | 拒单并保留原持仓，不补开盘价 |
| 已知开市但缺开盘价 | 拒单 |
| 涨跌停未知 | 拒单；合成无涨跌幅限制的场景需显式声明 `no_price_limits=True` |
| 有限价 | 同时提供有效上下限；滑点及分价舍入后到达涨停的买单、到达跌停的卖单拒绝 |
| 开盘容量未知 / 为零 | 分别记录拒单原因；明确的有限容量允许部分成交 |
| 公司行为未知或未处理 | 拒单，不能用价格连续或空事件列表证明无公司行为 |
| 现金不足 | 买入缩减到可支付含费金额的最大合法股数，连最小数量也不足时拒绝 |
| 小额卖出费用超过现金加卖款 | 拒绝，防止最低佣金造成负现金 |

`LotRule` 将买卖最低数量与递增数量分开，必须按具体证券和当时规则提供。
合成样例采用普通股买入 / 卖出最低 100 股、100 股递增；科创板最低 200 股、1 股递增。
可卖数量不足卖出最低数量时允许全部一次卖出，不能拆分这些零股。
这些是显式输入参数，不是依据代码前缀自动推断的完整交易所规则数据库。

等权函数先按全部持仓的可见收盘价估值，再计算每只目标证券的原始目标股数，
最后对目标与现有股数之差应用买卖交易单位。现有股数低于最低买入数量不意味着必须清仓。
退出股票池的持仓也要求收盘价和交易单位。缺失持仓价格直接报错，不把该头寸估值为零。
目标数量不预知次日开盘价；费用、容量和未成交会使实际权重偏离目标，未成交余量不会自动跨日续单。

## 费用与估值

费用通过 `CostModel` 显式传入：佣金比例 / 每笔最低佣金、过户费、买卖滑点、按生效日排序的
卖出印花税表。各金额使用 Decimal 和 `ROUND_HALF_UP` 舍入到人民币分，成交价也舍入到分。
这是合成 A 股样例的报价与结算假设，不覆盖其他币种或不同最小报价单位。
一次调用每笔订单聚合为一个成交，最低佣金按该聚合成交收取；没有模拟订单拆成多次成交的收费政策。

结果保存请求数量、实际数量、状态、部分成交 / 拒单原因、各项费用和现金变化。
有成交的部分订单进入成交集合及账本。现金余额须与逐条现金变化相等。
`mark_to_market(..., asof=...)` 要求显式上海日内知识时点以及每个非零持仓的同日可见收盘价；
任何缺价、未来价格或证券错配都失败。仅现金账户不需要虚构价格。

## 公司行为与交易状态的下一层契约

本版 `ActionGuard` 只表达“本次合成会话是否明确无需处理公司行为”，默认未知。
任何持有或下单证券未获许可都会阻止整个会话，避免绕开未处理的现金 / 股份变化继续交易。
它不实现真实分红、送转、配股和权利处理。正式账本接入前必须按以下语义扩展，不能压进
Phase 0 简化的单一 `event_date/factor/cash_per_share` 来掩盖日期差异：

后续的 [合成公司行为模块](CORPORATE_ACTION_CONTRACT.md) 已在独立层实现现金分红与整数送转股生命周期，
通过 `execute_session` 复用本执行器；其门禁仍须显式提供，未接入真实候选或完整估值。
以下真实数据与业务字段要求继续适用。

| 事件 / 证据 | 所需日期与字段 | 账本约束 |
| --- | --- | --- |
| 现金分红实施 | 登记日、除息日、支付日；税前每股现金；税收政策及持有期依据 | 登记日确定权益；除息与现金到账分开，未知税后表达不能任意取一个数 |
| 送股 / 转增 / 拆并股 | 权益登记、除权、股份到账及上市可交易日；按旧股计的转换比例 | 股数变化、单位成本和 T+1 / 上市限制分别处理；新增股不提前可卖 |
| 配股 | 登记日、认购期、认购价、配股比例、除权及获配股份上市日 | 认购是单独选择与现金支出，不作为免费拆股；未知上市日不能推断可卖日 |
| 预案 / 批准 / 实施 / 更正 | 事件 ID、阶段、来源版本、公告精度、实际观察及可用时间 | 按知识时点选择版本；实施字段不能回填为预案日已知 |
| 停复牌 / ST / 退市 / 限价规则 | 上海生效日及早晚时段、各字段证据与覆盖范围 | 名称含 ST、缺行情、零成交量、没有选中公告均不能自动产生完整交易资格 |
| 无公司行为证明 | 明确证券、日期范围、所覆盖的行为类型和来源覆盖依据 | 年度不分红决议只能覆盖该年度利润分配事项，不能推出全年无任何公司行为 |

已有 601916 配股材料只确认所选停复牌及除权日期，获配股份上市日仍未核实；
000938 不分红决议不覆盖全部行为种类。保留的状态参考中 `available_time=null`、
`can_trade=null` 不转换为执行器的已知无行为或开市状态。

正式接入需要成员版本与临时调样覆盖、行为 / 交易状态覆盖、可用时间政策、实际执行成本与容量假设。
当前 336 只原始范围、33 个缺价和条件成员诊断保持原样；缺价不计算零收益。
本契约补充了可实现的字段和拒绝语义，没有认证真实数据或冻结正式回测 / 模型划分。

## 运行与产物

在项目已准备好的独立环境执行：

```powershell
.venv\Scripts\python.exe -m pytest -q tests/test_execution.py tests/test_execution_smoke.py
.venv\Scripts\python.exe scripts/run_execution_smoke.py
```

Linux 使用同一环境的 `.venv/bin/python`。每次 smoke 新建 UTC 时间戳加随机后缀目录，
默认位于 `artifacts/experiments/synthetic/`，不覆盖旧成功或失败产物。
`inputs.json` 包含日历、初始持仓、信号价、执行观察、交易单位、成本、行为声明和参与率；
订单、账本和结果分文件保存。manifest 绑定实际加载的源码根、提交 / 脏状态、文件摘要、命令、
解释器及运行时间；输出文件也保存 SHA-256。执行器与脚本所属根不一致时拒绝出具成功报告。
失败返回非零退出码并留下失败 manifest、已产生的文件及 traceback。

通过要求卖出优先、普通股容量部分成交、科创板数量、现金逐分核对、T+1、完整持仓估值和
下一交易日停牌拒卖全部符合固定合成样例。样例净值仅用于账本核对，不是收益率或策略绩效。
