## 接口与已解决的问题

`value_at_close` 校验账本摘要和阶段链，要求本日收盘后、当时已知的显式未复权价格。
未到账股份按调用方声明的同证券收盘价假设计值；已经到账但仍锁定的股份也计入资产。
仅持有现金应收时无需股价。应收转现金、待到账股转持仓都只改变资产类别，不重复增加总资产。

缺价、未来价格 / 状态、复权价、未知公司行为范围及已登记却未完成除权计提的事件被拒绝。
调用方的处理完成和范围声明只是合成场景输入，不代表真实历史覆盖已被认证。
状态、价格及调用方输入不被修改，旧账本 / 执行器接口和导出结构保持各自语义。
细节见[估值契约](VALUATION_CONTRACT.md)。

本批还修复了 Decimal 上下文导致的分组误差：在较低精度下，相同资产到账前 NAV 为
41.8671、到账后为 41.8670；默认 28 位精度也会截断长小数。
现在状态恢复、权益复核与估值均使用独立的充分精度上下文，并明确限制支持的数值范围。
不继承调用方的运算精度与陷阱，不对每个证券或资产类别另作分位舍入。
原账本现金及合成代扣的分位舍入沿用原规则。
