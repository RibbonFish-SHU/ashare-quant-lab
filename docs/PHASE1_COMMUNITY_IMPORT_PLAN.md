## 执行与所有权

执行代理在集成后的已知 main 上创建独立 worktree，复用本项目 Python / Qlib 环境。
负责适配源码、相关离线测试、新候选构建及执行报告；主代理负责方案、审阅和集成。
不重下归档，不访问受限 BaoStock，不下载最新包，不读取 2024–2025 行情，
不运行模型 / 回测 / GPU，不同步服务器。

## 实现边界

1. 显式离线导入入口，输入归档、来源描述、历史范围、证券计划和新输出目录。
   校验整个归档摘要、原发布资产身份与日期、成员路径 / 类型 / 重复、文件大小、
   float32 起始偏移和交易日历边界；拒绝目录穿越、链接、超限成员、损坏和未来数据。
   上游脚本仅作口径参考，不能执行其安装、更新、发布或进程清理逻辑。
2. 保留归一化 OHLC / factor 原值，再单独记录恢复的 `normalized / factor` 价格。
   精度来源标为 float32 恢复，不能冒充原始精确十进制报价。
   原量 / 额和试验性单位换算明确分开；未知 / 不精确的量额不能填成准确股数。
   缺值、上市前区间、停牌参考与缺少状态参考分别记录，不前向填充成可交易行情。
3. 每行保存归档及 feature 成员摘要、索引 / 日期定位、来源版本、实际观察时间。
   release 日期与下载时间都不能当作 2023 年每条行情的历史发布时间。
   没有发布者 manifest / digest 的事实继续可见；本地摘要用于绑定保存的字节。
4. 行情候选和质量报告支持离线参考比较，逐股票统计覆盖、缺值、OHLC 分币比较，
   以及原始浮点误差。匹配不代表独立上游或完整 PIT 资格，仍为 `research_eligible=false`。
   不覆盖原包、旧候选、旧比较或此前失败记录；不改写原来源请求成功计数。
5. `csi300.txt` 单独保留为原始成员参考，不能直接作为正式股票池。
   本批记录年初 300 只互证、六月迟到 12 个交易日、十二月缺更新 15 个交易日；
   若生成按公告修正的派生集合，保留每次增删的原件、发布时间粒度和生效日期，
   不把“仅有两个定期事件”的未认证假设藏进代码默认值。
6. 巨潮公司行为样本继续单独保留。每股现金权利与总股本口径除息扣减不同，
   不能仅凭社区 factor 跳变构造事件；本批不顺带扩大到全市场公司行为采集。
